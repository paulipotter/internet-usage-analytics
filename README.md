## Description
This is a simple Django website I spun up for my senior project class in May 2018. The website contains its own database and uses javascript's D3 library to display charts as a result from a survey conducted in Paraguay.

## To Run this project:
```
git clone https://github.com/paulipotter/internet-usage-analytics.git
cd internet-usage analytics
pip install -r requirements.txt
python manage.py runserver```
